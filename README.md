# 단간론파 1·2 Reload 한국어 패치

《단간론파 1·2 Reload》 **PS Vita 일본판**의 비공식 한국어 패치입니다. 1편과 2편이 한 번에 적용됩니다.

**[0.9.0 패치 받기](https://github.com/lf-idonotknow/Danganronpa-12-Reload-PS-Vita-Korean-Patch/releases/tag/v0.9.0)** · **[오류·번역 제보](https://github.com/lf-idonotknow/Danganronpa-12-Reload-PS-Vita-Korean-Patch/issues/new/choose)**

## 한글화 내용

- 1·2편 본편 대사와 선택지, 메뉴, 도움말
- 학급재판과 미니게임에서 표시되는 문구
- 일부 게임 내 이미지와 영상의 일본어 문구
- PS Vita 전자 설명서

## 설치하기 전에

Windows 64비트 PC와 PS Vita 일본판(`PCSG00202`)이 필요합니다. **기본판 `01.00`으로 설치할 수 있습니다.** 공식 업데이트 `01.01`을 설치해 둔 경우에는 설치기가 그 상태를 자동으로 확인합니다.

릴리스의 **Assets**에서 이름 끝이 **`win-x64.zip`**인 파일을 받고, PC 폴더에 **모두 압축 풀기**를 하세요. 압축을 푼 폴더에서 `Danganronpa12KoreanPatch.exe`를 엽니다. 첫 설치 때 필요한 도구를 받으려면 인터넷에 연결되어 있어야 합니다. PC에는 15GB 정도, 실기로 복사할 저장소에는 4GB 정도의 여유 공간을 확보해 주세요.

| 플레이 환경 | 설치기에서 선택할 항목 |
| --- | --- |
| USB로 연결한 PS Vita | **PS Vita에 설치** |
| Windows의 Vita3K | **Vita3K에 설치** |
| PC에 원본 백업이 있고 비타에 직접 복사하려는 경우 | **실기용 패치 폴더만 만들기** |

### PS Vita에 USB로 설치

1. 비타에 일본판 게임을 설치하고, **rePatch 플러그인**이 활성화되어 있는지 확인하세요.
2. 게임을 완전히 닫고 **VitaShell**을 여세요. **START**를 눌러 **SELECT button**을 **USB**로 설정합니다. **USB device**에는 게임이 설치된 메모리나 SD2Vita를 선택하세요.
3. 설정을 닫고 USB 케이블을 PC에 연결한 다음, VitaShell에서 **SELECT**를 누르세요. PC에 USB 드라이브가 나타나면 설치기에서 **PS Vita에 설치**를 누릅니다. 드라이브 선택 창이 뜨면 해당 USB 드라이브를 고르세요.
4. **완료** 창이 뜨면 VitaShell USB 연결을 종료하고 게임을 실행하세요. 비타의 `ux0:rePatch/PCSG00202`에 패치가 적용됩니다.

### Windows의 Vita3K에 설치

1. Vita3K 메뉴에서 본인이 보유한 일본판 게임을 설치하세요. 공식 업데이트를 쓰실 경우 이때 함께 설치합니다.
2. Vita3K 왼쪽 위 **Open(열기) → Open Emulated Storage Path(에뮬레이터 저장 위치 열기)**로 데이터 폴더를 열어 두고, **Vita3K를 완전히 종료**하세요.
3. 설치기에서 **Vita3K에 설치**를 누르세요. 폴더 선택 창이 뜨면 2단계에서 열어 둔 위치 중 `ux0` 폴더가 보이는 위치를 선택합니다. 포터블 설치의 기본 위치는 Vita3K 실행 파일 옆의 `portable/fs`입니다.
4. **완료** 창이 뜨면 Vita3K를 다시 열고 게임을 실행하세요.

Windows Vita3K의 일반 설치에서 기본판과 업데이트가 합쳐진 상태를 지원합니다. 게임이나 업데이트를 수동으로 배치한 뒤 설치기가 판본을 찾지 못하면 Vita3K 메뉴에서 일본판 원본을 설치한 뒤 시도해 주세요.

### PC에서 실기용 폴더만 만들기

1. VitaShell에서 보이는 `app/PCSG00202`를 폴더 구조 그대로 PC에 복사하세요. 공식 업데이트도 사용할 경우 `patch/PCSG00202`를 같은 백업 폴더에 복사합니다.
2. 원본이 암호화된 상태라면 비타의 `license/app/PCSG00202`도 같은 구조로 보관하세요. `app/PCSG00202/sce_sys/package/work.bin`이 있는 원본은 설치기가 그 파일을 사용할 수 있습니다. 설치기가 PC에서 복호화하므로 따로 복호화할 필요가 없습니다.
3. **실기용 패치 폴더만 만들기**를 누르고, `app` 폴더가 보이는 백업의 최상위 위치를 고르세요. 결과를 저장할 PC 폴더를 이어서 선택합니다.
4. 결과물인 `rePatch` 폴더를 VitaShell을 통해 비타의 `ux0:` 최상위에 복사하세요. 이미 `rePatch`가 있으면 폴더를 합칩니다. 다른 게임의 패치 폴더는 그대로 두세요.

### 설치가 잘 안 될 때

- **비타를 못 찾을 때** · VitaShell 화면에 USB 연결 상태가 표시되는지, PC에 USB 드라이브가 보이는지, **USB device**가 게임이 설치된 저장소인지 확인하세요.
- **패치 데이터를 못 찾을 때** · ZIP을 모두 풀고 실행 파일과 `patch-data.zip`이 같은 폴더에 있는지 확인하세요.
- **원본이나 판본이 다르다고 할 때** · 일본판 `PCSG00202`인지 확인하세요. Vita3K에서 다른 패치를 사용했다면 수정 전 일본판 게임을 다시 설치해 주세요. 업데이트를 설치하거나 제거해 판본이 바뀌면 한글 패치도 해당 판본에 다시 적용하세요.
- **파일을 읽거나 복사하지 못할 때** · 설치 대상이 연결되어 있는지, 필요한 여유 공간이 있는지 확인하고 다시 시도해 주세요. 설치 중에는 USB를 분리하거나 Vita3K를 실행하지 마세요.
- **패치를 원래대로 돌릴 때** · 실기는 `rePatch/PCSG00202`를 PC로 옮기면 됩니다. Vita3K는 게임을 닫고 원본을 다시 설치하거나, 설치기가 PC에 보관한 파일을 게임 폴더의 같은 위치에 복사하면 됩니다. 백업은 탐색기 주소 표시줄에 `%LOCALAPPDATA%\Danganronpa12KoreanPatch\Backups`를 넣어 찾을 수 있습니다.
